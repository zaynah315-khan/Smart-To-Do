 # 🌸 Smart To-Do

A modern task management application built with React.js and Supabase. Smart To-Do helps users create, organize, complete, filter, and manage their daily tasks through a clean and responsive interface.

---

## ✨ Features

- 🔐 Secure user authentication
- 📝 Create and manage tasks
- ✅ Mark tasks as completed
- 🗑️ Delete tasks
- 🏷️ Categorize tasks
- 🔎 Filter tasks by status
- ☁️ Persistent data storage with Supabase
- 🎨 Modern pastel-pink UI
- 🫧 Glassmorphism-inspired design
- 📱 Fully responsive layout
- ⚡ Fast Vite development environment

---

## 🛠️ Technologies Used

- React.js
- Vite
- JavaScript
- CSS3
- Supabase
- Supabase Authentication
